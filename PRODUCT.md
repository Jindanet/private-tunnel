# Product

## Register

product

## Users

People sharing a local website or TCP service who may have no networking background, and server owners setting up the service. Prioritize the desktop client, while keeping the administrator dashboard understandable. Thai and English are equally supported.

## Product Purpose

PrivateTunnel connects a local service to a public address through a self-hosted server. A successful first use means saving the server address and access key, choosing a local service, starting sharing, and copying the resulting address without needing to understand routing terminology.

## Brand Personality

Clear, calm, practical. Use familiar words, explain unavoidable technical terms, and give a concrete next action when something fails. The user confirmed this direction on 15 October 2026.

Dark mode is the default for both the desktop client and administrator pages, independent of the operating system theme. This preference was explicitly requested by the user on 15 October 2026. Use charcoal surfaces, readable bright text and a restrained blue accent; keep forms, dialogs and native desktop startup surfaces dark too.

## Anti-references

Avoid a terminal-like wall of configuration, unexplained acronyms, decorative effects, and showing every advanced option during first use. Do not imply that saving a profile proves that a server is reachable.

## Design Principles

- Make one next action obvious at every step.
- Offer useful defaults, with domain and routing choices available on demand.
- Keep connection status and the share address honest and easy to find.
- Explain recovery in the same place as the error.
- Preserve existing desktop, administrator, and CLI workflows.

## Accessibility & Inclusion

Support keyboard navigation, visible focus, associated field labels, larger text and reduced motion. Pair color with status text. Keep the Thai and English workflows equivalent. Use WCAG AA contrast as the design target without claiming certification.
