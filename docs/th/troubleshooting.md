# แก้ปัญหา

[ภาพรวม](../../README.th.md) · [เอกสารภาษาอังกฤษ](../en/troubleshooting.md)

| อาการ | ตรวจอะไร |
| --- | --- |
| กุญแจถูกปฏิเสธ | ใช้กุญแจแยกที่ออกจากเซิร์ฟเวอร์นี้ ตรวจการเปลี่ยน/เพิกถอนและประเภทอุปกรณ์หรือเดสก์ท็อป อัปเดตทั้งโปรไฟล์และสำเนางานเริ่มอัตโนมัติ |
| WebSocket ได้ 404 หรือ upgrade ไม่ผ่าน | ใช้ชื่อแอดมินและ control path ให้ตรง ตรวจ Nginx ชื่อเว็บสาธารณะไม่ใช่จุดเชื่อมต่อควบคุม |
| ใบรับรองหรือ WSS ผิด | ตรวจชื่อ ชุดใบรับรอง CA เวลา DNS และต่ออายุ ไม่ใช้การเชื่อมแบบไม่เข้ารหัสแทน |
| HTTP สาธารณะ 502 | เปิดบริการจริง ตรวจพอร์ต/โฮสต์จากเครื่องไคลเอนต์ และดูว่า tunnel ยังเชื่อมอยู่ |
| HTTP 504 | ตรวจความคืบหน้ากับ `HTTP_IDLE_TIMEOUT_MS` เวลาหยุดนิ่งต่างจากเวลาทั้งคำขอ |
| คำตอบยาวขาดกลางทาง | ตรวจการหลุดหรือหยุดนิ่ง หลังส่ง header แล้วระบบปิดคำตอบเมื่อผิดพลาด ไม่แทรกข้อความ gateway ลง body |
| ชื่อที่ต้องการใช้ไม่ได้ | ตรวจกติกาโดเมน ไวยากรณ์ รายการที่เชื่อมอยู่ และการจองออฟไลน์ของอีกกุญแจ เปลี่ยนรหัสเดิมรักษาเจ้าของ แต่ออกกุญแจใหม่ไม่เหมือนกัน |
| TCP ในเครื่องได้ แต่นอกเครือข่ายไม่ได้ | เปิดพอร์ตที่แจกในทุกไฟร์วอลล์/NAT ตรวจ DNS และลองจากอีกเครือข่าย การประกาศช่วงไม่ได้ยืนยันว่าเปิดจริง |
| พอร์ต TCP เปลี่ยน | ใช้ `host:port` ล่าสุด ระบบข้ามพอร์ตที่ถูกใช้หรือถูกจองเมื่อเชื่อมใหม่ |
| Android หยุดแชร์ | ตรวจสิทธิ์เบื้องหลัง แบตเตอรี่ และ Termux:Boot ตัวลองเชื่อมใหม่ไม่สามารถคืนโปรเซสที่ถูกปิดเองได้ |
| เริ่มอัตโนมัติขึ้นเก่าหรือไม่พบ | ตรวจพาธบริการ/บันทึก ตำแหน่ง runtime และสถานะบริการของ OS ติดตั้งใหม่หลังเปลี่ยนรหัสหรือไฟล์รัน และให้เป้าหมายเริ่มเองด้วย |
| หยุดแล้วกลับมาหลังบูต | `stop` หยุดถึงบูตหน้า ใช้ `startup remove ID` เพื่อถอน |
| เดสก์ท็อปเก็บหรือเปิดกุญแจไม่ได้ | ปลดล็อกที่เก็บรหัสของระบบ โดยเฉพาะ Secret Service/KWallet บน Linux กรอกใหม่เมื่อจำเป็น ระบบไม่ถอยไปเก็บข้อความเอง |
| แก้ `.env` แต่โดเมนหรือรหัสไม่เปลี่ยน | ค่ามีอยู่ในฐานข้อมูล ให้แก้หน้าแอดมิน ตรวจว่าเลือกฐานข้อมูล/พาธถูกก่อนรีเซ็ตอะไร |
| ซอร์สใหม่แต่ไฟล์ยังเก่า | เทียบ `--version` กับแท็ก ดาวน์โหลดไฟล์ให้ตรงระบบและติดตั้ง runtime งานบูตใหม่ การ push เลขรุ่นเดิมไม่เผยแพร่ไฟล์ใหม่ |

## สำหรับบอร์ด

| อาการ | ตรวจอะไร |
| --- | --- |
| ไม่เห็น Wi-Fi ตั้งค่า | ดู Serial 115200 รีเซ็ตตามปกติแล้วกด BOOT/FLASH ภายในสามวินาที อย่าค้าง GPIO 0 ตอนรีเซ็ต ปรับขาปุ่มให้ตรงบอร์ด |
| Wi-Fi ตั้งค่าหาย | ปิดหลังห้านาทีหรือรีสตาร์ตเมื่อบันทึก รีเซ็ตเพื่อเปิดใหม่หากยังไม่มีค่าที่ใช้ได้ |
| รอเวลาอยู่ | ให้เข้าถึง SNTP/DNS หรือกำหนดนาฬิกาที่เชื่อถือได้ก่อน TLS |
| TLS ล้มเหลวบน ESP8266 | ตรวจ CA จริง ชุดใบรับรอง เวลา heap และก้อนว่างใหญ่สุด โปรโตคอล 512 ไบต์ไม่ลด buffer TLS ของ core หากไม่พอใช้ตัวกลาง |
| `/status` ได้ 401 | ใช้ชื่อ `device` กับรหัสผ่านเข้าชม หรือ Bearer ของผู้ชม ไม่ใช่กุญแจเชื่อมต่อ |
| 403 / 415 | ปฏิเสธคำขอข้ามต้นทาง เซิร์ฟเวอร์ 1.4.0 บังคับ JSON ให้อัปเดตเป็น 1.4.1 ขึ้นไปเพื่อส่งข้อความ ฟอร์ม และไบนารี ฟังก์ชันบนบอร์ดยังปฏิเสธรูปแบบเองได้ |
| เจอหน้าเข้าสู่ระบบสองชั้น | ปิด ให้ผู้ชมกรอกรหัสผ่านก่อนเข้าเว็บ ของกุญแจอุปกรณ์นั้นเมื่อเฟิร์มแวร์มีระบบล็อกอินเอง มีผลทันที ไม่ต้องเปลี่ยนกุญแจในบอร์ด |
| 413 / 431 / 503 | body ไม่เกิน 1024 ไบต์ path 192 ไบต์ content type 64 ไบต์ และทำครั้งละหนึ่งงาน 503 ให้ลองภายหลัง |
| เส้นทางที่ลงทะเบียนได้ 404 | เทียบแบบตรงตัวรวม query ฟังก์ชันต้องเตรียมคำตอบที่ใช้ได้ ตรวจค่าคืนจาก API คำตอบ |
| บอร์ดหยุดลองใหม่ | รหัส/นโยบายถูกปฏิเสธหรือโปรโตคอลผิดอาจหยุดจนเริ่มหรือตั้งค่าใหม่ ดู `lastError()` กับบันทึกเซิร์ฟเวอร์โดยไม่พิมพ์กุญแจ |

แจ้งบั๊กพร้อมรุ่นหรือ commit ระบบหรือบอร์ด/core ค่าที่ลบรหัสแล้ว รหัสสถานะ และตัวอย่างที่เล็กที่สุด ลบกุญแจ รหัสผู้ชม ชื่อภายใน และ path ส่วนตัว อย่าโพสต์ registry หรือข้อมูล EEPROM ดิบ
