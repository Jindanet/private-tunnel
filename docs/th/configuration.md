# การตั้งค่าและย้ายรุ่น

[ภาพรวม](../../README.th.md) · [เอกสารภาษาอังกฤษ](../en/configuration.md) · [ตัวอย่างตัวแปรทั้งหมด](../../.env.example)

ตัวแปรสภาพแวดล้อมกำหนด listener ที่เก็บข้อมูล และกติกาการทำงาน โดเมน กุญแจร่วมเดิม และรหัสแอดมินใช้ตั้งต้นในฐานข้อมูลครั้งแรก หลังจากนั้นแก้ค่าที่จัดเก็บผ่านหน้าแอดมิน การแก้ `.env` ไม่ได้เขียนทับรหัสแอดมินหรือรายการโดเมนเดิม เปลี่ยน listener หรือที่เก็บข้อมูลแล้วต้องเริ่มโปรเซสใหม่

| ตัวแปร | ค่าเริ่มต้น / ความหมาย |
| --- | --- |
| `PRIMARY_DOMAIN`, `TUNNEL_DOMAIN` | ชื่อแอดมินกับโดเมนเผยแพร่สำหรับเริ่มครั้งแรก |
| `INTERNAL_HOST` | `127.0.0.1` เก็บพอร์ตภายในเป็นส่วนตัว |
| `WS_PORT`, `DASHBOARD_PORT`, `PROXY_PORT` | `8080`, `8081`, `8082` |
| `DASHBOARD_PASSWORD` | ใช้ครั้งแรกเมื่อยังไม่มีรหัสปัจจุบันหรือเดิม ว่างเพื่อสร้างไฟล์รหัสส่วนตัว |
| `TUNNEL_TOKEN` | กุญแจร่วมรุ่นเก่า ไม่ใช้กับกุญแจแยกตามปกติ |
| `ALLOW_SHARED_TUNNEL_TOKEN` | `false` เปิดเฉพาะเพื่อรองรับเจ้าของแบบร่วมเดิม |
| `ALLOW_UNAUTHENTICATED_TUNNELS`, `ALLOW_LEGACY_QUERY_TOKEN` | `false` คงค่านี้บนเซิร์ฟเวอร์ที่เข้าถึงผ่านเครือข่าย |
| `REQUIRE_DATA_TRANSPORT_V4` | `true` ข้อกำหนดเดสก์ท็อป ตัวแปลงอุปกรณ์แยกต่างหาก |
| `HTTP_IDLE_TIMEOUT_MS` | `30000` เวลาหยุดนิ่งต่อคำขอ รับจำนวนเต็ม 50–3600000 เริ่มนับใหม่เมื่อข้อมูลคืบหน้า |
| `TCP_ALLOWED_PORTS` | `30000-40000` พอร์ตที่ประกาศว่าเปิดไว้ให้แจก |
| `TCP_BIND_HOST` | ว่างใช้ interface ตามระบบ หรือระบุ IP ภายใน |
| `TCP_VISITOR_ALLOWLIST` | ว่างยอมรับทุกคน หรือคั่น IP/CIDR ด้วยจุลภาคเพื่อจำกัดผู้ชมจริง |
| `AUTO_FIREWALL` | `false` โหมดเก่าจัดกฎในเครื่องไม่ได้ตรวจการเข้าถึงภายนอก |
| `REQUEST_LOGGING` | `true` ปิดเพื่อไม่บันทึก metadata ใหม่ ไม่ลบข้อมูลหรือสำรองเดิม |
| `DATA_DIR` | `./data` ข้อมูลส่วนตัวที่เขียนได้กับทะเบียนกุญแจ |
| `DB_PROVIDER` | `sqlite` หรือเลือก `mysql` |
| `SQLITE_PATH` | ระบุแล้วมีลำดับเหนือ `DATA_DIR` หากไม่ระบุใช้ `DATA_DIR/tunnel.db` |
| `DB_PATH` | ชื่อเก่าสำหรับพาธ SQLite |
| `MYSQL_HOST`, `MYSQL_PORT` | `127.0.0.1`, `3306` |
| `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE` | บัญชีและฐานข้อมูลเฉพาะ ดูในไฟล์ตัวอย่าง |
| `DB_SYNC_TARGETS` | ว่าง ระบบ mirror สำหรับย้ายข้อมูลไม่ใช่สำรองหรือสลับอัตโนมัติ |
| `DB_SYNC_STRICT` | `true` เขียน mirror ล้มเหลวทำให้คำสั่งล้มเหลว แต่ไม่มี transaction ร่วมข้ามฐานข้อมูล |
| `DB_BOOTSTRAP_SYNC` | `false` เปิดเฉพาะการย้ายที่วางแผนและสำรองไว้ ไปยังเป้าหมายว่าง |
| `NODE_ENV=production` | ปฏิเสธ mirror ที่ไม่ใช่ฐานข้อมูลหลัก ใช้แหล่งข้อมูลหลักเดียว |

ตัวอย่างกำหนดทั้ง `DATA_DIR` กับ `SQLITE_PATH` ให้แก้ทั้งคู่เมื่อย้ายข้อมูล MySQL อาจสร้างฐานข้อมูลได้หากบัญชีมีสิทธิ์ หากไม่มี ให้สร้างก่อนและให้สิทธิ์ schema/ข้อมูลที่ต้องใช้ บัญชีบริการต้องเขียนข้อมูลของตัวเองได้โดยไม่ต้องให้เขียนซอร์สโปรแกรม

ค่าที่เก็บในหน้าตั้งค่ามีชื่อแอดมิน รายการโดเมน การอนุญาตชื่อย่อยหรือชื่อหลัก ที่อยู่ TCP และ control root ค่าเริ่มต้นของ root คือ `/_private-tunnel` ไม่ได้อ่านจากตัวแปรสภาพแวดล้อม เปลี่ยนแล้วต้องปรับ Nginx และ URL ไคลเอนต์ให้ตรงกัน

กุญแจร่วมเดิมที่ระบุเองต้องมี 32–4096 ตัวอักษร ASCII ที่มองเห็น ไม่มีช่องว่าง และไม่ขึ้นต้นด้วยข้อความตัวอย่างที่ห้าม ค่าไม่ว่างที่ผิดทำให้เริ่มไม่ได้แม้ฐานข้อมูลมีกุญแจแล้ว หากค่าที่เก็บเดิมผิดยังเข้าแอดมินได้ แต่ต้องแก้ก่อนรับ tunnel กุญแจแยกปกติให้เซิร์ฟเวอร์สร้าง ไม่ได้กำหนดเองผ่าน `TUNNEL_TOKEN`

## ย้ายรุ่น

สำรองก่อนและเก็บต้นฉบับจนตรวจรุ่นใหม่เรียบร้อย ขั้นตอนเหล่านี้อธิบายสิ่งที่เปลี่ยน ไม่ใช่ให้ลบฐานข้อมูลเดิม

- **1.0 → 1.1:** ระบุ `DB_PROVIDER=mysql` ถ้าเดิมใช้ MySQL เก็บ listener เป็นส่วนตัว สร้าง reverse proxy ใหม่ เลิกส่งรหัสใน query และถอดตัวแปรช่วง TCP เก่า อย่าให้ค่าเริ่มต้นใหม่ทำให้ได้ SQLite ว่างโดยไม่ตั้งใจ
- **1.2 กุญแจแยก:** ออกกุญแจแยกแล้วสร้างหรือเลือกรายการให้ตรง ชื่อที่จองด้วยเจ้าของแบบร่วมไม่ย้ายไปกุญแจใหม่ให้เอง เปลี่ยนรหัสเดิมรักษา ID กับชื่อที่จอง ออกกุญแจใหม่ทั้งหมดเปลี่ยนเจ้าของ
- **1.3 เริ่มอัตโนมัติและ Termux:** ไฟล์เดี่ยวในซอร์สรันด้วย Node ได้ ติดตั้งแต่ละเป้าหมายบูตให้ชัด และติดตั้งสำเนาใหม่เมื่อเปลี่ยนรหัสหรือ runtime
- **1.4 อุปกรณ์:** กุญแจเดสก์ท็อปเดิมใช้รูปแบบเดิม การสร้างกุญแจอุปกรณ์เพิ่ม `type` และแฮชรหัสผู้ชมใน `client-keys.json` เซิร์ฟเวอร์เก่าปฏิเสธช่องที่ไม่รู้จัก ต้องสำรองให้สอดคล้องกันก่อนเริ่มใช้ หากถอยรุ่นให้ใช้สำรอง registry/ฐานข้อมูลที่เข้ากันก่อนเพิ่มอุปกรณ์ ไม่ลบช่องจากข้อมูลที่กำลังใช้งาน เฟิร์มแวร์ต้องใช้กุญแจอุปกรณ์ ไคลเอนต์เดสก์ท็อปไม่ต้องเปลี่ยนโปรโตคอล

การลงชื่อเข้าด้วยแฮช SHA-256 ของแอดมินรุ่นเก่าจะย้ายเป็น scrypt หากใช้ก่อน **2027-01-01 UTC** หลังวันนั้นปฏิเสธแฮชเดิม อัปเดตและเปลี่ยนรหัสก่อนกำหนด เก็บข้อมูลเริ่มต้นและกู้คืนเป็นส่วนตัว
